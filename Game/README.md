# 水蛇洞經紀人（v0.4：序章＋正式營業＋晚上）

## 怎麼開始玩

1. 先關閉 Unity 編輯器，雙擊 `輸出遊戲.bat`，等一到三分鐘。失敗的話，原因寫在 `build.log`。
2. 之後雙擊 `開始遊戲.bat`，或直接打開 `Build\水蛇洞經紀人.exe`。
3. 標題畫面選「開新遊戲」，可以選擇從序章開始，或跳過序章直接營業。

在 Unity 編輯器裡也可以輸出：上方選單「水蛇洞 / 輸出 Windows 遊戲」。

## 序章：鬼東的最後一堂課

七堂課加一場考試：接待客戶、文件查驗、商品交易、工商談判、羅傑的工商災難、仲介與企劃、投資與財務、最終考核，最後鬼東退休。

## 正式營業

鬼東退休後，電腦會變成工作桌面。目標是把公司的**現金**存到 NT$30,000,000。

### 每天的流程

1. 左邊的**委託信箱**每天會進來新的案子，最多放 6 件，大多隔天就過期。
2. 一天只有幾個**通話時段**（一開始 3 個），挑會賺錢的案子按「撥打」。
3. 通話裡用序章學到的方法處理：比對文件、提出質疑、議價、簽約或退回。按「掛斷」可以暫緩，之後再打。
4. 按「結束營業」看當天結算：工商入帳、配息、出租收入、房租水電、羅傑的事件、行情新聞。
5. 結算完是晚上，可以出門或回家睡覺（見下一節）。

### 晚上

結算之後會到晚上的街上。每晚有 3 段時間，可以：

| 地點 | 可以做什麼 |
|---|---|
| 辦公室 | 翻新庫存的設備（有刮傷變近全新、故障品修到能用）、研究明天的行情 |
| 光華電子街 | 正派商店，照標價買賣、不能議價。貨架上有設備和道具（提神飲料、宵夜禮盒、金屬探測器、頭燈），也收你的庫存 |
| 深夜跳蚤市場 | 超便宜的二手貨，可以殺價。不能檢測，可能有問題，也可能是贓物 |
| 垃圾場 | 挖寶：一趟挖 3 堆（有金屬探測器挖 5 堆），可能挖到故障品、刮傷品，運氣好挖到近全新的好貨 |
| 阿財熱炒 | 請廠商喝一攤，關係變好，明天可能直接介紹工商；還能聽到行情消息 |
| 星光網咖 | 挖掘新人（明天會打來談加盟）、打聽想買你庫存的買家 |
| 福德宮 | 添香油錢或抽籤，明天的直播出包機率減半 |
| 巷口宵夜攤 | 請羅傑吃宵夜，心情和信任上升，還會聽到他的心事 |
| 頂樓酒吧（第三幕） | 找大老闆聊聊，可能談到大案子，也可能遇到可疑的人 |

- 待在辦公室疲勞 +1，出門疲勞 +2。疲勞越高，隔天越容易**睡過頭**：會錯過一通客戶的電話，太累還會睡到中午、少一個通話時段。
- 什麼都不做直接回家，隔天精神飽滿，所有客人的耐心 +1。
- 晚上跑人脈得到的委託，信箱裡會用藍綠色框標示「人脈」。

#### 商店（電子街、跳蚤市場）

- 貨架上每件商品都寫著用途、價錢和轉賣行情。點一下或拖到下面的桌上，右邊就會出現結帳或議價。
- 電子街：照標價結帳，不能議價。「賣東西」分頁可以把庫存賣給店家，店家會照真正的狀況估價。
- 跳蚤市場：放到桌上後可以殺價，出價一樣是固定的「照價、-10%、-20%、-30%」，滑鼠移上去看成功率。先按「仔細檢查」，找到瑕疵或贓物的跡象，老闆會心虛、成功率變高。殺價失敗會扣老闆的耐心，扣完就不賣你了。

#### 垃圾場

- 地上有電器堆、紙箱堆、雜物堆，點一堆就挖。電器堆比較常挖到故障品，紙箱堆比較容易有好貨，雜物堆比較多廢鐵，偶爾會被野貓抓。
- 挖到的商品直接放進庫存（成本 0）。故障品、刮傷品可以晚上在辦公室翻新，再出租或轉賣。
- 金屬探測器：每次多挖 2 堆。頭燈：看得出哪幾堆裡面有商品。兩個都在電子街買。

#### 星期活動

| 星期 | 地點 | 活動 |
|---|---|---|
| 週一 | 電子街 | 新品日：全新、近全新 9 折 |
| 週三 | 跳蚤市場 | 清倉夜：老闆開價 8 折 |
| 週四 | 跳蚤市場 | 新貨到：多兩個攤位 |
| 週五 | 電子街 | 收購祭：賣給店家多 1 成 |
| 週六 | 電子街 | 週末特賣：全館 85 折 |
| 週日 | 垃圾場 | 回收日：多四堆，好貨變多 |

街上有活動的店門口會掛「活動」牌子。

### 案子種類

信箱上的標籤是**對方想做的事**：「出售」是對方要賣東西給你，「收購」是對方要跟你買東西。藝人檔案會列出藝人討厭的所有工商類別，喜歡的類別寫在頭像下方。

| 種類 | 怎麼賺 | 要注意 |
|---|---|---|
| 工商 | 替藝人接業配，直播完成才入帳 | 合約可能寫錯金額、名字、日期、賠償、時數、排他、公司名；藝人討厭的品牌容易出包 |
| 出售（對方要賣） | 跟賣家買二手設備進庫存 | 先送檢測，賣家常隱瞞刮傷、維修、故障；有檢測設備才查得到贓物 |
| 收購（對方要買） | 把庫存賣給買家 | 有瑕疵就老實講，不然可能被客訴 |
| 仲介 | 從三位藝人中推薦符合需求的人，拿佣金 | 類型、預算、檔期、偏好都要對。藝人報價照標準公式：（2 萬 + 粉絲數 × 1.5）× 類型係數（電競 1.3、美妝 1.2、歌唱 1.1、遊戲和戶外 1.0、料理 0.9、聊天 0.85）× 各幕行情 |
| 企劃 | 組一場符合需求的直播企劃 | 成本越低，企劃費越多 |
| 投資 | 投資新創，每 3 天配息，6 期後拿回本金 | 企劃書的數字跟財務試算對不上，就是有問題 |
| 簽約 | 新藝人想加盟 | 經紀合約的分潤、簽約金要對照意向書 |
| 糾紛 | 羅傑出包、撞期、排他衝突、侵權時會出現 | 期限內沒處理就照全額賠；先道歉、別否認事實、逐條反駁 |
| 灰色案件 | 報酬特別高的工商 | 看授權書和公司登記；接了可能被追償、被查稅 |

### 工商派人

旗下有兩位以上藝人之後，工商可以自己決定派誰去。把資料倉庫裡的「旗下藝人」放到檢視區，按按鈕打開選人面板，每位藝人都會列出類型、粉絲、喜歡和討厭的類別、直播那天有沒有空。

- **對方指定藝人**：可以「提議換人」。換成粉絲比較少的人，費用照比例變少（不喜歡這類產品再少一點）；對方不會接受討厭這類產品、或粉絲不到原本一半的人，提了會扣耐心。換人之後，原本那位的名字、檔期、排他問題就不算了，改看實際去的人。價錢談好之後就不能再換人。
- **對方不指定藝人**（信箱寫「不指定藝人」）：報價單上寫著希望的類型和最少粉絲數，一定要先選人才能簽約。
  - 最合適（類型對、喜歡這類產品、粉絲夠）：直播完廠商加碼 2 成。
  - 合適（類型對或喜歡這類產品，粉絲夠）：正常入帳。
  - 勉強：直播當天有兩成機會被廠商解約，這場沒有收入。
  - 不合適（討厭這類產品，或什麼都不符合）：有一半機會被解約。
- 派去的人那天有事，一樣會開天窗。

### 跨日後果

- 合約裡沒抓到的錯誤會在直播當天發作：撞期會開天窗、名字寫錯會被扣款、排他衝突會被別家求償。
- 羅傑的心情、信任、喜好會影響出包機率。可以讓他放假或加薪。
- 收進來的贓物會被警察沒收，隱瞞瑕疵會被客訴，灰色案件可能被追償或查稅。
- 現金不夠付帳時會自動向銀行借款，每天付利息，有錢會自動還清。

### 主線

| 階段 | 條件 | 發生什麼 |
|---|---|---|
| 第一幕：一人工作室 | 開始營業 | 只有羅傑一位藝人 |
| 第二幕：水蛇洞開始賺錢 | 現金一百萬 | V老大加入：多一個時段、可以委派、開放企劃與灰色案件 |
| 第三幕：實況產業商人 | 現金五百萬 | 案子金額變大 |
| 第四幕：三千萬計畫 | 現金一千五百萬 | 羅傑和 V老大越來越可疑 |
| 終章：三千萬的婚禮 | 結算時現金三千萬 | 固定結局，婚禮上誰會出現，看你一路上的選擇 |

### 電腦桌面右邊的分頁

- **行程**：接下來 7 天的直播、私人行程、求償截止日，還有昨天的新聞。
- **藝人**：粉絲、心情、信任、喜好；放假或加薪。
- **庫存**：成本與目前行情；出租（每天收租金）或賣給回收商。
- **投資**：配息進度，也可以提早出場。
- **公司**：聲譽、每日開銷、公司升級（人脈、檢測設備、市場情報、合約比對軟體、辦公室擴建、法務、公關、攝影棚等）。
- **帳本**：現金、待入帳、資產與最近幾天的利潤。
- **手冊**：鬼東的工作手冊重點。

存檔：每天開始、每通電話結束時自動存檔。存檔會先寫到暫存檔再換掉正式存檔，寫到一半當機也不會弄壞。

- 存檔寫不進去（例如硬碟滿了）時，畫面上方會出現橘色提示。
- 「繼續遊戲」時存檔壞掉，會說明原因，並把壞掉的檔案另存成 `save1.broken.json`。
- 遊戲資料（劇情、案件、正式營業資料）讀不出來時，標題畫面會列出是哪個檔案、什麼問題。

## 操作

- 下方資料倉庫：點一下放進空的檢視格，或拖到任一格替換。已經在檢視區的，再點一下就收回。
- 在兩份不同文件上各點一個欄位，再按「提出質疑」。
  - 寫錯的欄位，對上任何一份寫著正確內容的文件都算數（例如甲方寫錯，拿名片或報價單的客戶來比都可以）。
  - 寫錯的欄位，對上手冊裡管這件事的規則也算數（例如名字寫錯對「藝名要寫對」）。
  - 同一組欄位能證明好幾個問題時，會先算還沒提過的那一個。
- 議價單：從固定的出價挑一個，按下去就送出。要收錢的案子是「照價、+10%、+20%、+30%」，要付錢的案子是「照價、-10%、-20%、-30%」，都以對方現在的開價為準。注意視訊下方的耐心條。
  - **成功率**平常看不到：滑鼠移到出價按鈕上才會顯示（手機是按住按鈕，滑開再放開就不會出價）。在對方底線以內一定成交；越貪心成功率越低；成功率 0% 代表喊太高，對方會生氣（耐心扣兩格）。
  - 沒談成時對方會還價、耐心扣一格，而且對方的極限會收緊，同一個價錢一直重試成功率會越來越低。
  - 找到的問題就是籌碼：每抓到一個合約錯誤、瑕疵或疑點，對方的底線就往我們這邊移，同樣的價錢成功率變高（收購時就是能用更低的價錢買到）。
  - 正式營業的每一種案子都能議價：工商與灰色案件談合作費用、收購談收購價、出售談售價、仲介談佣金、企劃談企劃費、投資談投資金額、糾紛與查稅談和解金、新藝人談簽約金。
- 鍵盤 Esc：打開或關閉選單。

## 網頁版、手機、平板

- 輸出：先關閉 Unity 編輯器，雙擊 `輸出網頁版.bat`，會輸出到 `WebBuild`；V2 的 `main` 分支存放 `WebBuild` 產物，`source` 分支存放這個 Unity 專案。
- 手機請橫著玩。直著打開會先提示轉向（也可以按「直接玩」，但字會很小）。
- 手機、平板上，遊戲畫面會塞滿整個螢幕並避開瀏海；網頁不會被拖動，也不會被雙指放大。
- 全螢幕：畫面旁邊的黑邊上有「全螢幕」按鈕。
  - Android：按下去進入全螢幕，並鎖定橫向。
  - iPhone：Safari 不能讓網頁全螢幕，按下去會說明怎麼「分享 → 加入主畫面」；之後從主畫面打開就是全螢幕，也不會有網址列。
- 觸控操作：點一下等於滑鼠點擊；倉庫文件、商品都可以用手指拖。議價單的成功率要按住按鈕才看得到，滑開再放開就取消。
- 手機上沒有 Esc，改點畫面上的「選單」按鈕。
- 手機上按鈕可以點到的範圍，比畫出來的再大一點，比較不會點歪。
- 存檔存在瀏覽器裡。換瀏覽器、用無痕模式或清除網站資料，存檔就不會跟著。
- 遊戲是 640x360 的像素畫面。手機橫向大約顯示成原尺寸的 0.9 到 1.1 倍，字比較小；平板會比較舒服。

## 設定

顯示模式（視窗、全螢幕）、像素縮放（整數倍、盡量放大）、對話速度（慢、中、快、立即）。

- 畫面一律維持 16:9，多出來的地方是黑邊，不會把畫面拉扁或拉長。
- 視窗大小會依螢幕自動決定（例如 1920x1080 用 1280x720，2560x1440 用 1920x1080）。
- 整數倍模式下，如果整數倍會讓畫面縮得太小（例如 1366x768 的筆電），會自動改用剛好塞滿的比例。
- 視窗模式拖曳邊框改了比例，放開後會自動調回 16:9；按最大化則保持原樣，只留黑邊。

## 調整與擴充

- 想加品牌、商品、藝人、企劃選項或升級：改 `Main/world.json`。
- 想調整節奏：`Game/Career.cs` 最上面的 `Tiers`（各幕金額倍率）、`Overheads`（每日開銷）、`ActCash`（各幕門檻）。
- 主線劇情：改 `Story/career.json`（`intro`、`act2`、`beat3m`、`act3`、`beat10m`、`act4`、`beat22m`、`beat28m`、`ending`）。
- 存檔位置：`%USERPROFILE%\AppData\LocalLow\SSD Studio\水蛇洞經紀人\save1.json`。
